# TokenHub New User Free Trial (docs summary)

Source: Tencent Cloud docs “New User Free Trial Package” + techpedia claim guide (2026).

## Rules
- One free trial package per **root/primary** account (per model claim-once semantics)
- Campaign noted through **2026-12-31** (confirm page for extensions)
- Language models: free quota often **1,000,000 tokens**, **90 days** from claim
- Free consumed first; unused expires
- Non-transferable, non-stackable, non-cash-refundable
- **Credit card not listed as required to claim free quota**
- After free exhausted:
  - post-paid **disabled** → service stops
  - post-paid **enabled** → billed per token

## Claim methods
1. **Manual:** TokenHub console → Model Gallery → **New User Free Trial** → select models → Claim Now
2. **Auto:** first invocation of an eligible model claims free for that model

## Models mentioned in promo copy (examples)
DeepSeek-V4 / V3.2 family, GLM-5.x, Kimi-K2.x, MiniMax-M3/M2.x, Hunyuan-related, etc.  
Always re-read live gallery — list changes.

## Ops advice
- Claim only models you will use within 90 days
- Keep post-paid off until intentional spend
- Free tier is for evaluation, not unlimited multi-account farming (ToS)
